# Project guidance

- Build this project with Canvas and plain JavaScript, starting in `index.html`.
- Prefer maintainable, understandable code and clear component structure.
- Choose simple solutions; avoid unnecessary abstractions.
- Preserve existing UI unless a visual change is explicitly requested.
- Explain tradeoffs before making large architectural changes.
- Run the relevant build or test after implementation, and avoid unrelated changes.
- The project owner is a UI/UX and game systems designer, so keep implementation choices and explanations approachable.
